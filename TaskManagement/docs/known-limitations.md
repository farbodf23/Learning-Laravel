# محدودیت‌های شناخته‌شده پروژه Kasbify

## ۱. مقدمه

این سند محدودیت‌ها و قابلیت‌هایی را که در نسخه فعلی پروژه Kasbify پیاده‌سازی نشده‌اند، مشخص می‌کند.

هدف از این مستند، شفاف‌سازی محدوده فعلی پروژه و تفکیک تصمیم‌های طراحی از محدودیت‌های فنی است.

## ۲. محدودیت‌های مربوط به محدوده پروژه

موارد زیر به‌عنوان تصمیم‌های آگاهانه در محدوده فعلی پروژه در نظر گرفته شده‌اند و لزوماً نقص فنی محسوب نمی‌شوند.

| مورد | توضیحات |
|---|---|
| عدم وجود رابط کاربری | پروژه صرفاً شامل بک‌اند و REST API است و رابط کاربری گرافیکی ندارد. |
| عدم ثبت‌نام کاربران | امکان ثبت‌نام از طریق API وجود ندارد. حساب‌های کاربری از طریق Seed کردن دیتابیس ایجاد می‌شوند. |
| عدم مدیریت فروشگاه‌ها از طریق API | ایجاد، ویرایش و حذف فروشگاه‌ها و مدیریت عضویت کاربران از طریق API در محدوده فعلی پروژه قرار ندارد. |
| عدم حذف وظایف | برای جلوگیری از حذف ناخواسته اطلاعات و حفظ تاریخچه، endpoint حذف وظایف ارائه نشده است. |
| عدم حذف یا ویرایش نظرات | نظرات پس از ثبت از طریق API قابل ویرایش یا حذف نیستند. |
| عدم ارسال اعلان | سیستم در حال حاضر اعلان خودکاری برای تخصیص وظیفه، تغییر وضعیت یا ثبت نظر ارسال نمی‌کند. |

## ۳. محدودیت‌های فنی

### ۳.۱. عدم تضمین تغییرناپذیری تاریخچه در سطح دیتابیس

جداول `task_comments` و `task_events` به‌صورت append-only در طراحی برنامه در نظر گرفته شده‌اند.

در سطح برنامه:
- برای این مدل‌ها قابلیت ویرایش و حذف از طریق API ارائه نشده است.
- ستون `updated_at` برای آن‌ها تعریف نشده است.

بااین‌حال، در نسخه فعلی از Trigger یا محدودیت سطح دسترسی دیتابیس برای جلوگیری قطعی از اجرای دستورات مستقیم `UPDATE` و `DELETE` استفاده نشده است.

بنابراین، تغییرناپذیری این اطلاعات در سطح API و منطق برنامه رعایت می‌شود، اما در سطح دیتابیس تضمین کامل نشده است.

### ۳.۲. عدم وجود سیستم اعلان و یادآوری

سیستم فعلی مکانیزمی برای ارسال اعلان یا یادآوری خودکار درباره موارد زیر ندارد:
- نزدیک شدن زمان سررسید وظیفه
- عقب افتادن وظیفه از زمان سررسید
- تخصیص وظیفه جدید به کاربر
- تغییر وضعیت وظیفه

### ۳.۳. محدودیت در مدیریت کاربران و عضویت‌ها

مدیریت حساب‌های کاربری و عضویت آن‌ها در فروشگاه‌ها خارج از محدوده API فعلی است. برای آزمایش سیستم از کاربران و عضویت‌های از پیش تعریف‌شده استفاده می‌شود.

## ۴. قابلیت‌های پیاده‌سازی‌نشده

قابلیت‌های زیر در نسخه فعلی وجود ندارند و در صورت توسعه‌های آینده می‌توانند به پروژه اضافه شوند:

- خروجی گرفتن از فهرست وظایف در قالب CSV یا Excel
- ارسال اعلان از طریق ایمیل یا سایر کانال‌ها
- یادآوری خودکار وظایف نزدیک به موعد مقرر
- مدیریت کامل کاربران و فروشگاه‌ها از طریق API
- ثبت و مشاهده گزارش‌های مدیریتی پیشرفته

این موارد در حال حاضر جزو الزامات پیاده‌سازی‌شده پروژه نیستند.

## ۵. جمع‌بندی

نسخه فعلی Kasbify قابلیت‌های اصلی مدیریت وظایف، احراز هویت، کنترل دسترسی مبتنی بر نقش و عضویت در فروشگاه، اعتبارسنجی داده‌ها، مدیریت وضعیت وظایف، ثبت نظرات و نگهداری تاریخچه رویدادها را فراهم می‌کند.

محدودیت‌های ذکرشده، محدوده فعلی پروژه را مشخص می‌کنند و می‌توانند مبنایی برای توسعه نسخه‌های بعدی باشند.
